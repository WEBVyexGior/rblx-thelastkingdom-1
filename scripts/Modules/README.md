# scripts/Modules

Reusable **system libraries** (portable ModuleScripts) required by Client/Server/Shared —
e.g. a Signal/event primitive, a state machine, an inventory data structure.

Synced to `ReplicatedStorage.Modules` by both place project files.

**Empty in Phase 1 by design.** Distinct from `scripts/Shared`, which holds game-specific
constants/config/net/types/utilities. Add libraries here as phases need them.

(This README is ignored by Rojo; it only documents the folder.)
